# Model artifacts

This directory contains pipelines and metadata generated by training. Artifacts from experimental
runs remain outside Git during local development.

M3 uses `artifacts/m3/<run_id>/` for the pipeline, its manifest, and a local recovery bundle. For
the frozen public run `b15bab7b54bc2e1f`, only `pipeline.joblib` and `artifact_manifest.json` are
versioned; the local recovery bundle remains ignored. The exact pipeline is required because
reserializing it with Joblib on another operating system does not preserve its SHA-256. `train`
still makes it possible to reproduce the workflow without rebuilding the final bundle. Losing that
bundle does not authorize another holdout read: the versioned receipt and ledger remain the source
of truth.

Reviewable JSON results, plots, and documentation live in `reports/modeling/` and are versioned.
The ledger that prevents reopening the same holdout is separate from the run, indexed by the
holdout SHA-256, and versioned in `reports/holdout_access/`.

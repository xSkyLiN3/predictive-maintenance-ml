Assess machine failure risk

Enter the six variables for one observation. If they fall within the reference envelope, the model will return a score and compare it with the frozen decision threshold; outside that envelope, it will issue neither a score nor a classification.

Educational scope

AI4I 2020 is a synthetic dataset. The score is not calibrated and does not estimate remaining useful life (RUL). This demo has not been validated for real-world industrial use. Do not use it for safety, actual maintenance, or operational decisions. The API compares each input with a reference envelope derived solely from training data, not with a general out-of-distribution (OOD) detector; outside that envelope, it returns neither a score nor a classification.

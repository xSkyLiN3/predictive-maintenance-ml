AI4I · observación individual

Evalúa el riesgo de fallo de una máquina

Introduce las seis variables de una observación. Si quedan dentro de la envolvente de referencia, el modelo devolverá un score y lo comparará con el umbral validado; fuera de ella no emitirá score ni clasificación.

Alcance educativo

AI4I 2020 es un dataset sintético. El score no está calibrado, no estima vida útil restante (RUL) y no valida uso industrial. No lo uses para seguridad, mantenimiento real ni decisiones operativas. La API compara cada entrada con una envolvente de referencia obtenida solo de training, no con una detección general de OOD; fuera de ella no entrega score ni clasificación.
